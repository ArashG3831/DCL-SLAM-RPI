# آماده‌سازی مخزن برای تحویل

شاخه فعلی فقط راهنماها را نگه می‌دارد. سورس Robot 2، ابزارهای WSL و سورس معتبر Robot 1 هنوز باید جداگانه انتخاب و به مخزن افزوده شوند. پوشه Pi یک درخت Git تغییرکرده دارد و خروجی ساخت، گزارش، داده و نسخه‌های آزمایشی متعددی در آن جمع شده است. کل پوشه را برای ساخت مخزن تحویل کپی نکنید.

## ساختار پیشنهادی

~~~text
robot-system-handoff/
├── README.md
├── docs/
├── wsl/
│   ├── helpers/
│   ├── source/
│   ├── config_templates/
│   └── installers/
└── robots/
    ├── robot1/
    └── robot2/
        ├── setup/
        └── src/
~~~

فایل‌های راه‌انداز فعال، پروفایل‌های SLAM و Nav2، بسته‌های محلی لازم، تنظیم Zenoh و نسخه دقیق وابستگی‌های بیرونی را نگه دارید. برای Robot 2، منبع معتبر را از نسخه نصب‌شده روی Pi یا نسخه پشتیبان بررسی‌شده انتخاب کنید. کد Robot 1 را تا زمان یافتن نسخه معتبر آن وارد نکنید.

## داده‌هایی که نباید منتشر شوند

این موارد خروجی اجرا یا اطلاعات شخصی‌اند و نباید وارد Git شوند.

- پوشه‌های **build/**، **install/** و **log/**
- حافظه نهان، محیط مجازی Python و فایل‌های موقت
- rosbag، داده خام حسگر، نقشه‌های تولیدشده، ویدئوها و گزارش‌های حجیم
- کلیدهای SSH، گذرواژه‌ها، فایل‌های **.env** و تاریخچه پوسته
- تنظیم‌های شخصی WSL و فایل‌های دارای نشانی NAT لپ‌تاپ
- نسخه‌های پشتیبان فشرده مانند **robot1.rar**

الگوهای زیر نقطه شروع مناسبی برای **.gitignore** هستند.

~~~gitignore

~~~

الگوهای سراسری برای فایل‌های Python یا پوشه **test/** را نادیده نگیرید. آن‌ها ممکن است کد منبع یا آزمون‌های لازم باشند. IPهای آزمایشگاه و مسیرهای وابسته به نام حساب ویندوز را نیز پیش از انتشار بررسی کنید.

## چک‌لیست انتشار

- فقط شاخه‌های منبع و فایل‌های لازم برای ساخت را انتخاب کنید.
- فایل‌های نصب‌شده و گزارش‌های تاریخی را بیرون از مخزن نگه دارید.
- نسخه ROS، مخازن خارجی و شناسه نسخه هر وابستگی را ثبت کنید.
- نصب و ساخت را در WSL تازه و روی هر دو Pi بررسی کنید.
- مسیرهای شخصی، IPها، کلیدها و گذرواژه‌ها را پیش از انتشار جست‌وجو کنید.
- فرمان‌های راه‌اندازی و توقف را با حساب SSH دانشجوی بعدی اجرا کنید.

تا وقتی این موارد انجام نشده‌اند، این شاخه را راهنمای مستنداتی بدانید، نه بسته نرم‌افزاری آماده نصب.
